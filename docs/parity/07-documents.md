# 07 Document endpoints

Two endpoints, present only when documents are enabled (CFG-14). Documents are served per Upstream Service; there is no merged document.

Express routes both as `GET` (and so `HEAD`) on the raw path, ignoring ASCII case and allowing one trailing slash (`/DOCUMENTS`, `/document-json/`). Any other method or path, including `/document%73` and `/documents//`, goes to the proxy, as do both paths when documents are disabled. Neither endpoint runs middleware or rate limiting.
