# 05 Rate limiting

Counters live in Redis so that several gateway instances share them. Redis key names and scripts are not part of the External Contract (ADR 0001); the behaviour below is. This file covers Routed Requests; MCP calls are in [08-mcp.md](08-mcp.md).

Tests: Conformance Tests in `conformance/harness/tests/conformance/rate_limit.rs` (`rate_limit::…`); unit tests in `crates/rust-gateway/src/rate_limit/` (`rate_limit::tests::…`, with golden vectors generated from the reference's own packages by `testdata/generate.mjs`); Rust-only tests against a real Redis in `crates/rust-gateway/tests/rate_limit_redis_*.rs`. Rows with a `C` stay `todo` until the `rust` target passes their Conformance Tests.
