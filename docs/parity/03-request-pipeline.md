# 03 Request pipeline

How an HTTP request is classified and what runs before it is forwarded. Forwarding itself is in [04-http-forwarding.md](04-http-forwarding.md); the rate-limit steps are detailed in [05-rate-limiting.md](05-rate-limiting.md).

| REQ-26 | A path containing malformed percent-encoding (for example `/svc/v1/users/%zz`) is rejected before any other step, for every request class, with 400 and body `{"message":"Failed to decode param '%zz'","error":"Bad Request","statusCode":400}`. The message quotes the first segment that fails, whole: `/svc/a%zz/%yy` gives `'a%zz'`, `/svc/v1/users/%41%zz` gives `'%41%zz'`, `/svc\%zz` gives `'svc\%zz'` (backslashes are not converted).
